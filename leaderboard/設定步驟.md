# 🏆 排行榜設定步驟（約 5 分鐘）

排行榜的成績會存進**你自己的 Google 試算表**。照下面做完後，把最後拿到的網址傳給 Claude，就會幫你接進遊戲並上傳。

---

## 1. 建立試算表

1. 打開 <https://sheets.new>（用你的 Google 帳號登入），會自動開一個新的空白試算表。
2. 左上角把檔名改成 **今天要排擠誰 排行榜**（名字隨意，方便自己找）。

## 2. 貼上排行榜程式

1. 試算表上方選單：**擴充功能 → Apps Script**，會開一個新分頁。
2. 左邊會看到 `程式碼.gs`（或 `Code.gs`），把裡面原本的內容**全部刪掉**。
3. 打開本資料夾的 `apps-script.gs`，**全部複製**，貼進去。
4. 按上方的 💾 **儲存**（或 Ctrl+S）。專案名稱可以取「排行榜」。

## 3. 部署成網址

1. 右上角藍色按鈕 **部署 → 新增部署作業**。
2. 「選取類型」旁邊的 ⚙️ 齒輪 → 選 **網頁應用程式**。
3. 設定：
   - 說明：隨意，例如「排行榜」
   - **執行身分：我**
   - **具有存取權的使用者：所有人**　← 一定要選這個，朋友才能上傳
4. 按 **部署**。
5. 第一次會要求授權：
   - 按 **授予存取權** → 選你的 Google 帳號
   - 出現「Google 尚未驗證這個應用程式」是正常的（因為這是你自己寫的程式）→ 點左下 **進階** → **前往「排行榜」（不安全）** → **允許**
   - 這個權限只是讓程式能寫入**這一份**試算表。
6. 完成後會顯示 **網頁應用程式網址**，長得像：
   `https://script.google.com/macros/s/AKfy................/exec`
   按 **複製**。

## 4. 把網址傳給 Claude

把那串 `.../exec` 網址貼到對話中，Claude 會：
- 填進遊戲 `CONFIG.leaderboardUrl`
- 實際測試上傳與讀取
- 上傳更新到 GitHub Pages

---

## 之後怎麼管理

- **看所有紀錄**：打開那份試算表，每一次上傳都是一列（時間、暱稱、難度、秒數、擊退數）。
- **刪除不雅暱稱或可疑成績**：直接刪掉那一列，排行榜馬上就不會顯示。
- **清空重來**：刪掉第 2 列以後的所有資料（保留第 1 列標題）。
- **同一個暱稱**只會顯示他最快的那一次。
- 通關時間低於 45 秒的成績會被自動拒絕（不可能那麼快）。

## 注意

- 如果之後修改了 `apps-script.gs` 的內容，要重新「部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本 → 部署」，網址不會變。
- 排行榜是公開的，拿到遊戲網址的人都看得到暱稱，建議朋友用暱稱、不要用全名。
